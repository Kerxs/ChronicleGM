## 一、需要你确认的改进点

1. **新手引导换成了游戏教程**：原来的四步引导（Onboarding）已删除，第一次打开时由 GM 玻璃球带着走 14 步；世界菜单里的「使用引导」改名为「游戏教程」。暂停后下次打开会接着来（并自动打开示例世界）。
2. **示例世界「雾湾 · 灯塔守夜」**：我手写的原创内容（灯塔熄灭、守塔人、两个可选角色）。名字和设定可以改，你看是否合适。
3. **「主持人视角」改成了全局「剧透模式」**（默认关闭，打开时有警告）：关闭时，图谱、人物关系、搜索结果、游戏面板、档案馆、事件日志都由程序去掉主持人信息；**控制台和 NPC 记忆必须打开剧透模式才能看**。如果你平时自己当主持人，需要打开一次。
4. **"读档"＝从存档点开出新时间线**：进行中的战役也可以读档了（以前只能结束后回溯），原时间线保持不变。没有做"覆盖式读档"，因为会丢数据。
5. **永久删除战役**会临时解除事件日志"只能追加"的保护（只在那一个事务里，删前自动备份，删完立刻恢复）。如果你希望事件日志永远不可删，我可以改成"永久删除只清掉其他表、保留事件日志"。
6. **难度**（简单 / 普通 / 困难 / 残酷）放在游戏「角色」页的规则设置里，按战役保存；影响检定难度和临时敌人的等级。是否需要一个全局默认值？
7. **联网搜索**默认关闭；打开后可以手动搜，也可以勾选"允许 GM 搜索"（每小时次数上限）。**没有用真实 Key 测试过** Tavily / Brave，SearXNG 也只用了本地模拟服务。
8. **后台自动生成插图、立绘、语音**默认全部关闭（云端生图可能收费）。只把玩家可见的描述发给生图服务。
9. **语音输入**需要你配置一个 OpenAI 兼容的 `/audio/transcriptions` 服务。我在 GitHub 上找了三个可以本机运行的：whisper.cpp、FunASR（SenseVoice，中文好）、speaches，已做成预设，启动方法见 `docs/stt-services.md`。软件不下载、不安装这些服务。麦克风权限已经能用（发布版里实测可以录音），**但没有用真实识别服务测过**。
10. **货币与稀有度叫法跟随题材**（科幻用信用点、武侠用两银子和文钱……），AI 生成剧本时会一起给出；已有剧本按题材推断，可以在「玩法配置」里改。
11. **数据目录迁移**：复制 → 校验 → 重启后切换，旧目录保留由你自己删。位置记在 `%LOCALAPPDATA%\ChronicleGM-location.txt`。
12. **世界库升级到 v14**（新增：玩法配置、剧本版本、记忆压缩字段、战役回收站），资料库升级到 v4（请求计时）。第一次打开旧世界时会自动备份再升级。

13. **生成图片要你确认**（按你的意见改）：进入新地点或见到新人物时，不再自动生图，只在游戏页「待生成的插图」里列出建议。你可以改提示词，点「生成」先预览，满意了再「保存」，也可以「重新生成」或「不要」。
14. **GM 的讲述留在玻璃球里**：剧情区里 GM 的话变成「GM · 第 N 回合」小条，点开在球里看完整的一段，用 ◀ ▶ 翻看以前的讲述。玩家和 NPC 的话改成聊天气泡（玩家在右、NPC 在左）。
15. **开场白固定结构**：先说「欢迎来到《剧本名》」，再介绍剧本，然后介绍主角，接着讲眼下的处境，最后问"你打算怎么做？"。模型没写欢迎语时，程序会补上开头那句。

### 第二阶段：第 14～17 项
- **14 联网搜索**：Tavily / Brave / SearXNG 可配多家，Key 在凭据管理器；结果标明来源、用"资料，不是指令"包住；失败时退回模型自己的知识；不会写进剧本。
- **15 上下文压缩**：最近 8 条对话原样保留，更早的超过阈值时后台自动整理成增量摘要；记录压缩前后 token 数（llama-server 用 `/tokenize` 实测，否则估算）；可以确认、重新生成、删除；失败时原始记录不变。
- **16 剧透模式**：见第 3 点。
- **17 运行监控**：首字时间（流式）、生成速度、提示词速度、输入输出 token、上下文占用、语音实时率；平均 / 最快 / 最慢；拿不到的显示「不可用」。GM 请求在服务支持时改为流式（才能测到首字时间）。

### 第三阶段：第 18～23 项
- **18 筛选**：世界树「筛选」——按类型、名称文字、payload 字段（等于 / 包含 / 范围 / 有这一项）、和谁有关系、在哪个节点下面，条件同时满足。
- **19 缩略图**：新缩略图 480 像素；小 / 中 / 大 / 特大四档；"此刻的画面"地点大图用原图；以前的 256 像素缩略图在选大尺寸时后台重新生成。
- **20 数据目录**：见第 11 点；处理目录不存在、不能写入、目标非空、迁移中失败（清理并保持原位置）。
- **21 删除**：剧本、战役（回收站 / 永久删除）、世界（回收站）、摘要、事实（"忘掉"）、NPC 记忆、备份文件；删掉的内容在事件日志里留有记录。
- **22 智能面板**：根据回合的结构化结果弹出小卡片（任务、角色与背包、战斗、检定、地图、新发现），停靠在剧情区下方不遮挡；可固定、关闭，关掉的同一场景不再弹。不额外调用模型。
- **23 动态生成**：货币、稀有度叫法、叙事风格随剧本题材。

### 第四阶段：第 24～29 项
- **24 NPC**：每个故事日最多一次模型调用，让有目标的人物主动做一件事（只记成世界事件和人物记忆，不直接改状态，不会让人死亡）；同一地点的人物会碰面、关系变化；记忆随回合变淡；NPC 上下文加入它和其他人物的关系、近期世界动向。
- **25 世界模拟**：倒戈（和势力关系恶化、或势力瓦解后）、失踪（极度恐惧）、地点改变（势力瓦解后无人管辖）、势力瓦解。不随机死人。
- **26 因果**：GM 记下玩家决定的后果（可延迟 0–30 回合）；到期的后果交给 GM，发生后锁定、不能撤销；随时间线回溯。
- **27 难度**：见第 6 点；每次检定的说明里写明难度修正。
- **28 导演**：剧情阶段（铺垫 / 发展 / 高潮 / 收束）；伏笔埋下与回收，很久没回收的会提醒。
- **29 存档**：命名存档、快速存档、快速读档；见第 4 点。

### 第五阶段：第 30～35 项
- **30 关系**：剧透过滤（主持人可见的关系在剧透模式外隐藏）、战役中关系变化历史（人物关系页）。
- **31 环境**：各大地区天气不同；室内不受天气影响；光照（明亮 / 昏暗 / 漆黑）；黑暗和恶劣天气由程序给察觉、射击、攀爬等检定加修正，并写进说明；玩家提到火把等光源时减轻。
- **32 叙事风格**：风格、详细程度、对话 / 动作 / 心理 / 环境比例；人物的说话风格与口头禅进入 NPC 设定。
- **33 线索**：发现地点、相关人物、解锁条件；未解决线索（还没被任何推理用到）；剧透模式下列出还没发现的线索。
- **34 传闻**：公开事件变成传闻，先被当事人和所属势力知道，再在同一地点碰面的人之间传开，每传一手可信度降 15、说法越来越走样；NPC 以"听说（可信度 x%）"的方式知道。暗中进行的事不传。
- **35 剧情质量**：已死亡 / 失踪的人物在叙述里像在场一样出现、换了说法的泄露（双字重合度）→ 只作为主持人提示；人物性格一致性由导演的"剧情符合度"检查。
