# 反剧情纠正改革 · 代码审查报告

日期：2026-11-19。范围：GM 回合流程、提示词、导演、剧情 / 任务 / 事件状态、上下文构建、事后检查。

## 结论

改革前，GM 把玩家拉回主线主要靠下面几处。按影响从大到小排列，每处都写了处理方式。

| # | 位置 | 作用 | 处理 |
|---|---|---|---|
| 1 | `crates/gm/src/turn.rs`（原 484–497 行） | 停滞 N 回合后在上下文末尾加"必须让一件事发生……choices 里至少给一个推进主线的选项"，不受"只提示"设置控制 | **删除**。改为中性提醒："这本身没有问题，世界照常运转（要有因果依据），不要拉回主线" |
| 2 | `crates/gm/src/director.rs:185` + `core/src/director.rs:45` | 停滞时自动采用导演的第一条建议（默认开），并在 GM 上下文里保留 4 回合 | 默认**关闭**自动采用；"只提示"默认打开 |
| 3 | `crates/gen/prompts/director.j2` | 停滞时建议"让人物找上门、给时限"，优先使用剧本钩子；"剧情符合度"把偏离剧本当作扣分 | 建议必须写因果依据，可以不安排；钩子不再优先；偏离剧本只记录、不扣分 |
| 4 | `core/src/director.rs:425` | 默认偏好"偏离主线太远时给出回到主线的机会" | 改为"玩家决定故事走向，不拉回主线" |
| 5 | `crates/gm/src/context.rs` | 未开始的任务、剧情节点、可选分支和已发生的事实混在一起，没有"潜在 / 已确定"之分，也没有玩家目标 | 分段：玩家目标 → 已确定的事实 → 潜在内容（统一标"尚未发生，只是可能性"）；结束的任务、毁掉的物品不再列出 |
| 6 | 任务状态（自由文本 "" / active / done / failed） | 没有"拒绝 / 绕过 / 失效"，玩家拒绝后程序可能重新激活 | 新增 refused / bypassed / invalid / changed；结束的任务不能改回去 |

| 8 | 人物状态 | 没有阻止复活；失踪的人物仍能被选为发言人；没有日程的剧本人物到处都在场 | 复活被拒（`can_revive` 除外）；失踪不在场；离开场景后，没有日程、但写明了住处的人物只在住处 |
| 9 | `core/src/worldsim.rs` 触发器 | 条件满足就触发，不管剧情是否已经被玩家改变 | 已失效 / 被绕过 / 被改变的事件不再触发 |

没有发现"NPC 自动找上门"或"重新派发被拒任务"的程序机制；这些只会通过提示词（第 1、3 项）发生。

## 新增的机制

- **自由行动规则** `crates/gen/prompts/free_play.j2`：被 GM 规划、GM 叙述、导演三份提示词放在最前面引用，优先级高于剧本。NPC 提示词加了一条：NPC 按自己的目标行事，不是推动剧情的工具。
- **动态事件状态** `crates/core/src/events.rs`：
  - 存在战役记录 `plot_event` 里，随检查点、分叉、导出一起保存；旧存档第一次用到时自动补生成。
  - 共 8 种状态；终态（完成、失败、绕过、失效、被改变）不回退。
  - 必需的人物死亡 / 失踪、必需的物品被摧毁时，事件自动失效；条件满足时变成"可触发"。
- **新条件** `alive`：剧本可以写"这个人必须活着"。
- **GM 新输出字段**：
  - `player_goal`：玩家的目标；
  - `event_updates`：拒绝、绕过、改写、失效、完成、失败；
  - `destroy_items`：彻底毁掉的物品。
- **事实保护** `crates/gm/src/validate.rs::check_facts`：结束的任务、死去的人、毁掉的物品不能被效果推翻。
- **剧情纠正检测** `crates/gm/src/railcheck.rs`：
  1. 程序先找疑点，包括复活、物品再现、再次派发拒绝过的委托、把未发生的事写成已发生、没有因果的巧合、无视玩家目标；
  2. 交给模型（`rail_check.j2`）结合因果复核，有因果依据的来访会放行；
  3. 确认有问题时带着问题重写，仍不行就重新生成一次，再不行记入冲突。
  - 只改叙述，不回滚任何状态。选项里重新派发拒绝过的委托直接过滤。
- **界面**：任务面板显示新状态；GM 控制台新增「剧情事件」（状态和原因）和玩家目标。

## 测试

`crates/gm/tests/anti_railroad.rs` 覆盖方案的测试 A–F，并补了两条剧情纠正检测的测试（重写、放行），共 8 个，全部通过。原来的 `gm_mock` 测试按新默认值调整后全部通过。真实模型测试见 `docs/anti-railroad-report.md`。
