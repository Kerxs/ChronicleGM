# 云端语言模型 · 语音合成 · 生图 API · 完成报告

日期：2026-11-14。截图与走查日志在 `docs/cloud/`。

## 能做什么

「模型与性能 → 模型服务」新增「添加服务（云端或本机）」，替换了原来的"手动添加"表单。

1. 先选服务类型：**语言模型 / 语音合成 / 生成图片**。
2. 再选服务商，地址和常用模型会自动填好。
3. 填上 API Key 和模型。「获取模型列表」读取的是服务的 `/models`，不计费。
4. 点「添加并测试」。

| 类型 | 预设 | 接口 |
|---|---|---|
| 语言模型 | OpenAI、Anthropic Claude、Google Gemini、DeepSeek、阿里云百炼（通义千问）、月之暗面 Kimi、智谱 GLM、火山方舟（豆包）、硅基流动、OpenRouter、其他 | OpenAI 兼容 `/chat/completions`（原有的客户端：流式、结构化输出、看图、思考开关都照旧） |
| 语音合成 | OpenAI 语音（gpt-4o-mini-tts / tts-1，10 种声音）、硅基流动 CosyVoice、其他 | OpenAI 兼容 `/audio/speech`：`model`、`voice`、`response_format`（mp3 / wav）、可选的声音描述 `instructions` |
| 生成图片 | OpenAI 图片（gpt-image-1 / dall-e-3）、智谱 CogView、其他 | OpenAI 兼容 `/images/generations`：`model`、`prompt`、`n: 1`、`size`。支持返回 `b64_json`、`data[].url` 或 `images[].url`；返回地址时再下载一次，下载不带 Key |

### 语音合成

- **朗读路由**：「任务使用哪个服务 → 语音朗读」可以选云端语音；没设置时用第一个语音服务。
- **声音分配**：
  - 旁白用服务设置里的"旁白的声音"。
  - NPC 如果在人物资料里指定了声音，就用指定的；否则从"分给 NPC 的声音"列表里按人物 ID 固定选一个，同一个人每次的声音都一样。
- **缓存**：按"文字 + 声音 + 服务 + 模型 + 格式"缓存，可以存 mp3。本机 Breeze 的缓存文件名和以前一样，已有缓存继续有效。
- **本机 Breeze 不受影响**：请求和以前完全相同，有单元测试逐字段对比，也用真实 Breeze 实测过（见下文）。

### 生成图片

- **入口**：节点「图片」页签里的「AI 生成图片」。
- **描述**：按节点的标题、类型、摘要和玩家可见描述预填，可以修改，可以选风格和尺寸。主持人隐藏内容不会放进描述，有单元测试保证。
- **保存**：生成后先预览，并显示服务改写后的描述，点「保存到节点」才写入，同时生成缩略图。
- **调度**：请求走调度中心，优先级 P5，与世界生成同级，可以在性能中心里看到。

### 隐私与费用

- **隐私开关**：云端服务默认**不允许**发送内容，要在添加时勾选，或者在列表里打开「允许发送…」。
  - 没打开时：语音不会朗读，生图不会发请求，GM 和生成会明确报错。走查已验证这种情况下确实没有发出请求。
- **API Key**：只保存在 Windows 凭据管理器，不写数据库和日志。编辑服务时 Key 留空表示不修改。
- **「重新测试」**：
  - 语言模型：照旧实测对话、流式、结构化输出、看图。
  - 语音：合成"测试"两个字。
  - 生图：**只检查 Key 和模型列表，不生成图片**，避免产生费用。
- **路由**：语音和生图服务不会被自动设成默认（对话）路由，路由下拉框也只列出对应类型的服务。

### 云端流程走查（发布版 + 模拟云端服务器）

模拟服务器是 OpenAI 兼容的，绑在局域网地址 `10.13.6.200` 上，所以软件按"非本机"处理，走的是真实的云端代码路径。服务器要求正确的 Bearer Key。**这只验证软件的请求与处理流程，不代表任何真实服务。** 结果 20/20 项通过，日志在 `docs/cloud/cloud-run.log`：

- **添加语言模型**：
  - 用界面表单添加：「获取模型列表」带 Key 读到 3 个模型；
  - 非本机地址显示隐私开关，默认不勾选；
  - 保存后：需要 Key、Key 已在凭据管理器里、标记为非本机；自动测试对话 ✓。
- **语音**：
  - 没允许发送时：报错，且模拟服务没有收到任何朗读请求。
  - 允许后：返回 mp3，交给界面的是 `audio/mpeg`。请求带了 Key、模型、旁白声音、mp3，没有 Breeze 专有的 `seed`，也没有声音描述（已关闭）。
  - NPC 两句话用的是同一个声音（`v-a`）；第二次朗读来自缓存；「重新测试」合成 ✓。
- **生图**：
  - 不会被设成默认路由；没允许发送时报错、不发请求；「重新测试」没有生成图片。
  - 界面里生成：描述按节点预填，请求带 Key、模型、默认尺寸 `1024x1536`，显示预览和改写后的描述，确认后节点图片数从 1 变成 2。
- 控制台没有错误。走查结束后删除了测试服务和 Key，`cmdkey /list` 里没有残留。

### 本机 Breeze 回归（真实模型）

语音路由改写后，用真实 Breeze 测试：托管模型按需启动，合成 3.28 秒的 WAV，用时 7.9 秒，第二次来自缓存；结束后没有残留进程。

## 已知问题

1. 没有用真实云端 Key 验证。如果你提供一个 Key（或在软件里自己添加后点「重新测试」），可以实测。
2. 只支持 OpenAI 兼容接口。没有做各家的原生接口：Anthropic 原生 Messages、阿里百炼的异步生图（通义万相）、需要轮询任务的生图服务都不支持。
3. 硅基流动生图的官方参数名是 `image_size`，和 OpenAI 的 `size` 不同，所以没有放预设，可以用「其他」自己填。
4. mp3 的时长由界面播放时得到，后端不计算。
