## 功能

- **世界树节点图片**（节点详情新增「图片」页签）
  - 添加方式：选文件、拖进来或粘贴（Ctrl+V）。长边超过 2048 像素在界面里自动缩小。
  - 管理：大图查看、改说明、设为封面（第一张就是封面）、删除（需确认）。
  - 格式：PNG、JPEG、WebP、GIF。程序按文件头判断格式，不信任扩展名；单张上限 12 MB，每个节点最多 40 张。
  - 存储：图片存在世界文件里（新表 `node_images`，世界库迁移到 v9，升级前自动备份）。所以自动备份、从备份还原都包含图片。世界导入导出包新增 `images/` 目录：复制模式下图片跟着节点的新 ID 走，"从导入包新建世界"也会带上图片。永久删除节点时，图片随之删除。
- **AI 看图描述**：对节点图片生成一段 150–300 字的设定描述（人物外貌、地点风貌、地图上的地名与方位、物品等）。
  - 只返回文字，不会自动写入。你可以复制，或点「追加到摘要」；追加走正常的节点修改，进入修订记录，可以撤销。
  - 程序会去掉模型偶尔加上的 Markdown 标题和加粗。
- **用图片生成世界 / 剧本**
  - 入口：「一句话生成世界」、节点「AI 辅助」（生成子节点、扩写、重写）、剧本「生成大纲」都可以附带参考图片，最多 6 张。
  - 图片来源：可以上传（缩到长边 1280 像素的 JPEG），也可以勾选本节点已有的图片。
  - 提示词会告诉模型：把图里看得清的内容作为设定依据，看不清的不要当成事实。
  - 图片随任务参数保存，重试时用的是同一组图。生成结果照常进入审阅台，确认后才写入。
- **看图能力检测**：模型服务的「重新测试」新增「看图」一项，实测方法是发一张 16×16 的纯红色图片，看模型能否回答出颜色。
  - 没通过时，参考图片和 AI 看图描述都会明确报错，提示去重新测试，不会假装能用。
  - 没有附带图片时，发给模型的请求和以前完全一样。
- **请求格式**：有图片时按 OpenAI 兼容格式发送"文字 + 图片"的内容数组。

## 已知问题

1. 小字有时读不出：测试地图上 34 像素的"灯塔岬"没被读出，这是视觉模型自身的识别能力。
2. 一张大图约占 1500 个输入 token，6 张参考图会明显增加生成耗时。界面上传时已缩到长边 1280 像素来控制。
3. 图片没有接入游戏页（GM 叙述时不会给玩家展示节点图片），这次的范围里不包含。如需要，可以作为后续工作。
4. 树和图谱里还没有显示封面缩略图（后端已有 `node_covers` 接口，界面还没用）。
