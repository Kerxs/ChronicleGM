# Phase 4：调查、任务与 NPC 系统 · 完成报告

日期：2026-11-13。按任务书第七节实施。

## 设计要点
- **所有变化都有事件依据**：新增三种规则效果。
  - `adjust_mood`：NPC 情绪，原因必填；
  - `upsert_record` / `delete_record`：战役记录，用于调查板与动态任务。
  
  它们和其他状态变化一样走"效果 → 事件日志"，写入检查点，随时间线回溯恢复，参与重放校验与结局比较。世界库迁移 **v8** 新增 `campaign_moods` 和 `campaign_records`。
- **世界时钟**存在受保护变量 `time.minutes` 里（GM 不能直接修改），所以天然支持回溯。
- **普通日程由程序计算**：NPC 在哪里、在做什么、是否在场、离场时的活动，全部由程序按时间批量推算，**不调用模型**。

## 对照任务书

| 要求 | 实现 |
|---|---|
| 自动记录线索 | 剧本线索一旦揭示，就出现在调查板上；GM 在方案里写的 `discoveries` 自动记入（同名不重复）；玩家也可以记笔记 |
| 证据链 | 线索之间可以关联（支持 / 矛盾 / 相关）；程序沿"支持"关联找出间接证据，并列出与证据链矛盾的线索 |
| 线索关联 | 同上，可以修改、取消 |
| 玩家自主推理、允许错误推理 | 推理由玩家写，引用支持或反对的证据；状态（还在考虑 / 我相信 / 我否定）由玩家设定，**程序不评判对错** |
| AI 不直接替玩家揭晓答案 | GM 上下文里的调查板摘要标明"玩家的推理可能是错的"，提示词要求不确认、不否认、不替玩家串起线索；GM 写的任务变化和发现里如果出现"真相 / 推理 / 其实是"等词或原样泄露主持人信息，就只给主持人看、不记入调查板（启发式，见已知问题） |
| 主线、支线、隐藏任务 | 沿用剧本任务类型；隐藏任务开始前玩家看不到 |
| 前置、完成、失败条件 | 任务资料新增 `precondition` / `complete_when` / `fail_when`（规则 DSL），每回合结束时由程序判定并推进；剧本编辑器有表单 |
| 任务期限与变化 | `deadline_turns`（开始后 N 回合），过期自动失败；任务变化记录在 `quest_note`，显示在任务历史里 |
| 任务与 NPC、地点、线索关联 | `npc_ids` / `location` / `clue_ids`；任务页显示，已知的线索打勾 |
| NPC 日程（工作、休息、社交、地点） | 人物资料 `schedule`（时间段、活动、地点，可以跨过午夜），保存时校验格式；世界树的人物编辑页有表单 |
| 根据世界时间推进 | 每回合推进 GM 估计的时长（默认 15 分钟，最多 12 小时），也可以手动"等待" |
| 玩家不在场时也有合理行动 | 时间推进时，活动发生变化的 NPC 各记一条 `npc_activity`（批量、由程序计算） |
| 普通日程由程序计算 | 是；**在场判定改为按日程**：只有此刻在场景地点（或其下级地点）的 NPC 在场，死亡的不在场（Phase 0 报告里提到的"NPC 声称在不该在的地方"问题由此修正） |
| 信任、恐惧、愤怒、怀疑、压力、忠诚 | 恐惧、愤怒、怀疑、压力、忠诚记在 `campaign_moods`；信任沿用 Phase 3 的人物关系 |
| 情绪影响对话和行为 | NPC 的上下文包含当前情绪和此刻在做的事；情绪 ≥70 时附带行为提示（害怕想逃、愤怒不合作、怀疑不透露、压力大易说漏、忠诚愿冒险） |
| 记住玩家的重要行为 | 沿用 NPC 记忆 |
| 关系和情绪变化要有事件依据 | NPC 回应给出的情绪变化每项每回合最多 ±10，原因记录玩家的话；GM 提议的情绪变化同样有上限；情绪会随时间平复（每小时恐惧、愤怒、压力 −5，怀疑 −2），平复也会记录原因 |

### 联调中发现并修复的问题
1. **GM 的自由文本里出现编号**（例如"Q1 仍进行中""掌握了 C1"）：现在写入记忆、调查板、任务历史前，会把编号换成名称。
2. **GM 在玩家可见的任务变化里写了"指控村长的推理与真相相悖"**，等于告诉玩家推理错了：
   - 提示词新增规则，禁止评价玩家推理、提及真相；
   - 程序侧防护：含有剧透词或原样泄露主持人信息的任务变化只给主持人看，这类发现也不记入调查板。
3. **GM 把剧本里还没开始的任务当作"新任务"提出时，任务没有开始**：现在不重复创建，而是让已有任务开始。
4. **玩家声称不在场的人物出现时 GM 照单全收**：提示词新增"人物去向以日程为准"的规则。程序侧本来就不会让不在场的 NPC 说话。
5. **"仔细查看铁砧"之后 GM 没有揭示线索**：提示词新增"线索只能通过 reveal_clue 揭示"。之后的一轮中 GM 正确揭示了，另一轮仍用 set_flag 代替（见已知问题）。
6. **游戏页右侧 7 个页签挤成竖排**：样式已修正。

## 已知问题和尚未完成的部分
1. **模型不一定每次都用 `reveal_clue` 揭示线索**（3 轮里 1 次没有）。规则写在提示词里，但无法强制；漏掉时调查板上不会有这条线索。之后可以考虑：GM 叙述里出现线索标题时提醒主持人，或在 GM 控制台（Phase 7）里提供一键揭示。
2. **剧透防护是启发式的**：靠关键词和原样泄露检查，挡不住换了说法的暗示。
3. **任务的前置、完成、失败条件里有检定的部分不会自动掷骰**：只有条件确定为真时才推进。
4. **世界时间目前只有日和时分**：昼夜、天气、季节在 Phase 5 加入；日程暂时不区分星期或季节。
5. **NPC 之间的情绪与关系还不会自动变化**（只有对玩家的会在对话中产生），Phase 5 世界模拟时再扩展。
6. **期限按回合计算**，不是按故事时间。Phase 5 有日历后可以增加按时间计算的期限。
