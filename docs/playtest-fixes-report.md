## 一、改了什么

### 上一轮已写好、这次补上测试
1. **开局发放初始装备**：剧本生成角色、AI 生成角色时都会写 2–6 件随身装备（武器有伤害骰和射程，用弹药的武器写弹药名，弹药单独一叠写数量）。选角色时由程序检查后放进背包，第一件武器 / 护甲自动装备；背包已有东西时不重复发。旧剧本的角色没写装备时，开场前 GM 按身世推断一次（提示词 `pc_kit.j2`）。
2. **武器显示品质和剩余弹药**；战斗中每次射击从背包扣 1 发，没有弹药就「打不响」，这一击作废。
3. **检定技能贴合行动**：玩家说了「窃听 / 潜行 / 说服 / 搜查……」，模型却选了属于别的属性的技能（例如窃听用「野外生存」），程序改成对应的通用技能，并在冲突提示里写明。
4. **点名问 NPC 时保证他回答**：玩家的话里有「问 / 说 / 告诉……」并点了在场人物的名字，模型没让他说话时程序补上。NPC 台词改短（一两句、不超过约 50 字），少用语气词和括号动作。
5. **太久没有推进时推一把**：按节奏设置算出限度（松弛 10 回合 … 紧凑 3 回合），超过限度要求 GM 给出推动局面的新情况，超过两倍时要求这一回合必须有事情发生。

### 这次新做的
6. **检定「查看详情」没反应 → 已修**。原因：检定卡片跳到「状态」页，但检定记录只在剧透模式下显示，而且已经在状态页时什么都不变。现在：
   - 状态页总是显示「上一回合的检定」（技能、原因、完整计算过程），这不是剧透信息；
   - 点「查看详情」会切到对应页签、把右侧滚到眼前，并让卡片闪一下。
7. **手动掷骰选项**：游戏页右上「掷骰」下拉框（全局设置）：
   - **程序自动掷**（默认，和以前一样）；
   - **我来点击掷骰**：检定时回合停住，玻璃球展开显示「轮到你掷骰」，点「🎲 掷骰」；
   - **掷实体骰子，输入点数**：同上，但输入自己掷出的点数（优势 / 劣势要填两次，骰池填每颗骰子，空格分隔）。点数不合法时输入框变红、不能提交。
   - 都可以点「交给程序掷」；等待时点「取消」会结束回合。
   - 程序仍然校验点数（颗数、范围），掷骰记录写进事件日志并标记 `manual`，检定说明里写「亲手掷」。等待期间不占用世界文件（界面照常能读状态）。
8. **「主持人：」改名为「GM 笔记：」**（游戏页场景、人物 / 任务面板、审阅台、剧情编辑器、控制台）；角色页的数值调整行改为「GM 调整：」；几处过时的「主持人视角」提示改成「剧透模式」。
9. 顺手修的：状态页「物品」把初始装备显示成 `kit-01M7…` 编号 → 现在显示物品名；等玩家掷骰时剧情区的提示不再是「GM 正在构思」。

### 发现并修正的问题
| 现象（真实输出） | 修正 |
|---|---|
| "端起猎枪朝野狗开枪"只开了战，这一枪没结算、没扣弹，叙述却写一枪打死 | 开战回合轮到玩家且玩家说的是攻击，同回合结算这一击 |
| 战斗中只说"再开一枪"，程序什么都没做，GM 自己写"一枪击倒" | 战斗中玩家说攻击词、模型没给动作时按攻击结算 |
| 子弹打光、战斗结束后"再开一枪"，GM 改用"猎枪射击"检定照样开了枪 | 武器弹药为 0 时程序直接判"打不响"，不掷骰、不开战，并交给叙述 |
| 叙述写"擦着耳朵飞过——没有命中"，冲突检查却报"写了命中" | "没有 / 没能 / 未"后面的命中不算 |
| 结算里野狗还剩 5/11，叙述写"瘫软在地，不再挣扎"；没打中写"击中要害，当场倒地不起" | 新增"活着写成死了""没打中写成倒下"两种冲突；有冲突时按结算让 GM 重写一次，仍不符就保留提示；叙述提示加"有生命值就是活着" |
| AI 生成装备的栏位写"主手 / 腰 / 背 / 弹药"，伤害写"无 / d0"，射程 150 | 程序整理：有伤害骰的是武器、射程过大按 12 格、弹药不是武器、同名只留一件；字段说明写明只能填哪几个词 |
| 闲逛的三个回合叙述几乎逐字相同 | 和最近两段讲述有 24 字以上相同就带着重复句重写一次，仍重复记提示；提示词加"不要重复上一回合的描写" |
| NPC 每回合换着说法重复"雾还没散，船队还得等天亮""把石头给我" | NPC 提示里列出他最近说过的 4 句；和自己或这回合别人刚说的话有 6 字以上相同就重说，仍重复就略过这句 |
| 同一回合阿澜和莫伦说了一字不差的同一句 | 同上（这回合别人说过的也算） |
| 莫伦连续 9 回合不请自来地插话 | 玩家没叫、已经连着两回合插话的人物这回合不说话（玩家点名照常） |
| GM 用 ‘…’、'…'、"苏桦：……"（剧本格式）替 NPC 说话 | 这几种也识别为代说，删掉改由 NPC 自己回答 |
| 摘掉代说后留下"翼翼地检查着…""…不喜欢火光。’"`啪"地一声熄了。"`这样的残片；或者整段叙述被摘空 | 只在句子边界处切、允许混用的弯引号配对、删孤立的半截引语；摘完太短或为空就重新要一段不含台词的叙述 |
| "我翻翻自己的口袋"开了战，敌人是玩家自己 | 去掉名字是玩家角色的敌人 |
| "我还是在码头上闲逛"开了战，敌人是在场的阿澜和莫伦 | 玩家的话里没有敌意时，不和在场人物开战（新冒出来的怪物照常可以突袭） |
| 翻口袋时 GM 写"摸到备用灯芯石"（背包里没有） | 玩家查看自己时，把背包和钱作为程序事实交给 GM |
| 问"还剩几发铅弹"也掷了检定；问阿澜一句话也掷了聆听 | 查看自己、对在场人物提问时去掉检定 |
| 模型给了一条标题为空的"新发现"，整个回合失败 | 无效的发现只跳过并记提示，不让回合失败 |

### 最终一轮的结果（第 6 轮）
- 开场按身世推断出初始装备；生成的退伍老兵带猎枪 + 12 发铅弹，栏位全部规范。
- 猎人：问弹药答"三发" → 开战第一枪结算并扣弹 → 每枪扣 1 发 → 打空后"打不响" → 问剩几发答"已经射出"，背包剩 0。
- 灯塔：问苏桦她亲自回答（33 字）；偷听掷察觉（和聆听同一属性，程序不纠正）；问阿澜不掷骰；翻口袋只说背包里的东西；8 回合闲逛没有开战、没有大段重复（1 回合被程序标出"叙述和上一回合重复"）。
- NPC 台词 23–46 字，重复的 2 句被略过。

### 还剩的
- 9B 模型偶尔重写后仍然和上一回合重复半句（程序会在冲突提示里标出）；叙述偶尔把结算写偏（程序重写一次，仍不符就提示主持人）。
- 节奏推进：闲逛 8 回合里有新情况（雾、碎石、敲门声），但没有形成强推进；限度按节奏设置（默认适中 6 回合）。
