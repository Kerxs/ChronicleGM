## 已完成（8 个阶段）
1. **状态机** `crates/core/src/gamestate.rs`：设置 → 初始化 → 开场 → 探索 ⇄ 等待掷骰 → 战斗（转场 / 玩家 / 结算 / 敌方）→ 战后 → 结局；合法迁移写死，AI 无法写入；状态随时间线回溯、退出后可恢复。
2. **掷骰记录** `DiceRecord`：所有掷骰经 `campaign::roll_with` 统一收集，检定 / 攻击 / 伤害 / 先攻 / 闪避带加值明细（D20 + 属性 + 技能 + 装备 + 状态）。
3. **初始化 7 步** `crates/gm/src/init.rs` + `game_init` 命令：每步真实执行、幂等、失败停在那一步可重试。
4. **大厅** `ui/src/pages/Lobby.tsx` + 着色器玻璃球 `OrbCanvas.tsx`（旋转、粒子、折射、高光、悬停 / 点击、剧本主题色）；创作工具从「创作模式」进入，一个未删。
5. **游戏空间**：全屏、隐藏编辑器，面板改为 NPC 档案 / 关系图谱 / 地图 / 背包与属性 / 剧情历史；玻璃球从大厅平移到顶部并自动讲开场白。
6. **战斗引擎**：速度决定先攻、闪避、技能（瞄准 / 包扎 + 剧本自定义）、场景交互（货箱 / 油灯 / 重物）。
7. **战斗场景** `BattleScene.tsx`：电影化转场、网格战场、行动顺序、全部行动按钮、战后结算；AI 只按结算异步写描述（`combat_narrate.j2`）。
8. **3D 物理骰子** `lib/dice3d.ts`（three.js + cannon-es，按需加载）：先模拟再按落地朝上的面印真实点数，不平放会继续模拟；后台窗口也按时间走完；低性能模式用平面骰子。

## 真实模型试玩（2026-11-18，DeepSeek-V4-Pro-Qwen3.5-9B，本机 llama-server，不开 MTP）
完整走了一遍新流程：大厅 → 新开一局（扮演柯拉）→ 初始化 → 开场 → 4 个探索回合 → 开战 → 用战斗场景按钮打完 → 战后 → 继续冒险。

| 环节 | 结果 |
|---|---|
| 初始化 7 步 | 13.6 秒全部完成；第 3 步模型按身世推断装备用了 11.8 秒，预热 0.5 秒 |
| 开场白 | 43.5 秒（初始化后自动开始） |
| 探索回合 | 17–29 秒一回合；点名问莫伦，他亲自回答，台词简短 |
| 亲手掷骰 | 「点击掷骰」面板出现 → 点击 → 3D 骰子 → 按结果叙述 |
| 战斗 | 开战转场、先攻、敌人攻击、伤害都有 3D 骰子；攻击、瞄准、结束回合正常；AI 战斗描述异步出现；战败后进入结算页，「继续冒险」回到探索 |

试玩中发现并已修正：
- **开场白剧透**：开场素材里带了「核心设定与真相」（仅主持人可见），说出了「寻找失落的灯芯石、潮洞深处的谜团」。已去掉。
- **模型几乎不提检定**：4 个回合一次都没提，连「趁人不注意爬生锈铁梯」也直接成功。改为玩家做了明确有风险的动作（攀爬、潜行、偷听、撬锁、说服……）而模型没提时，由程序补一次检定。
- **潜行成功却被发现**：潜行成功撬箱子，莫伦马上喝问。改为潜行类检定成功、玩家又没对人说话时，在场人物这回合不做反应。
- **初始装备**：「铜币 ×12」改为放进钱包；护甲值为 0 的「行囊」不再当护甲穿上；模型乱写的弹药名（吉他的弹药写成「string」，战斗里「没有 string 了，打不响」）现在会被清掉，战斗里也只认世界里真实存在的弹药物品。
- **行动点不够时**：「攻击」按钮仍能点，点了只报错。现在行动点不够时禁用「攻击」、高亮「结束回合」，并提示还能做什么。
- **战斗描述编造武器**：没有枪的战斗里写了「举枪瞄准」「子弹擦过耳边」。现在把每个参战者手里的武器交给模型，并要求不得编造。
- **同一次检定在骰子托盘里出现两遍**：开发模式下事件监听漏退订。已修，同样的问题全界面一共修了 7 处。

**倒地后要先休息**（按你的决定）：生命降到 0 倒地时（规则是「倒地」而不是「死亡」），只能休息、向人求助或用药治疗，其他行动由程序拦下并说明原因，不调用模型，也不写进存档。休息时程序推进故事时间，按每小时恢复量至少恢复到能站起来（最少 1 小时），然后由 GM 讲述醒来。游戏页会显示倒地提示条，带「休息」「向人求助」两个按钮，同时隐藏 GM 的行动选项。

**游戏空间界面重做**（你指出大厅换了、聊天界面没换）：中间是限宽的剧情流，GM 叙述是带竖线的故事卡片，人物台词和玩家行动是左右对话气泡（带头像首字），掷骰和系统提示是居中的小胶囊；背景跟剧本主题色走。右侧改成图标栏（状态、记忆、线索、任务、NPC 档案、关系图谱、地图、背包与属性、战斗、剧情历史），点一下从右侧滑出抽屉，Esc 或 ✕ 收起；剧透模式、自动朗读、低性能模式、掷骰方式和运行监控收进底部的齿轮菜单。创作模式里的游戏页保持原样。截图：`docs/playtest-fixes/7-game-space.png`。

**统一的新款界面**（你的要求）：全软件统一成同一套风格：
- **背景**：启动动画、大厅、游戏空间、创作模式的所有页面都是浅灰点阵背景，彩色光斑全部去掉。
- **卡片**：全部改成半透明毛玻璃（能透出点阵）、圆角更大、阴影更轻。
- **玻璃球**：大厅、游戏空间、创作模式里的游戏页、游戏教程用的都是同一个 GPU 着色器球，球后面是跟剧本主题色走的点阵光环。
- **剧情流**：游戏空间和创作模式的游戏页都用新的故事卡片和对话气泡。
- **其他**：侧栏的「返回大厅」有了自己的图标。低性能模式下仍用静态球。
